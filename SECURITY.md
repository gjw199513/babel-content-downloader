# Security Policy

## Supported version

Security fixes currently target the latest published release.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/gjw199513/babel-content-downloader/security/advisories/new) when it is available for the repository. If private reporting is unavailable, open an issue that contains no secret, credential, private URL or exploit detail and ask the maintainer for a private contact channel.

Do not attach browser profiles, runtime configuration files, client tokens, collected private content or signed media URLs to a public report.

## Scope

Reports about local runtime authentication, extension-to-runtime pairing, output-directory authorization, URL or network policy bypass, credential leakage and unsafe archive or media handling are especially useful. This project does not support bypassing paywalls, private-content controls, DRM or access restrictions.
