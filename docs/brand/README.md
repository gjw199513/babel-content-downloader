# Logo

以 Babel 的字母 B 为主体，用错落的层叠结构呼应巴别塔及汇集的内容卡片；下部留白形成向下箭头，表达保存到本地。深青底、米白主体与薄荷绿强调色。

- `logo.png`：当前选定原图。
- `logo-preview.png`：256 像素 README 预览。
- `../../extension/icons/`：16、32、48、128 像素扩展图标，由原图等比缩小。

生成方式：内置 image_gen。此版取代早期的书本方案，最终提示词如下。

```text
Use case: logo-brand. Design ONE premium browser extension app icon for Babel Content Downloader. Brand idea: Babel = tower of many languages and knowledge; product = collecting diverse web articles, videos and audio into a local library. Create a DISTINCTIVE CAPITAL B MONOGRAM built from three bold staggered horizontal tiers of a compact Babel tower. The two rounded right-hand bowls of B are clearly readable; the stepped tiers subtly look like stacked content cards. Integrate ONE small downward-pointing negative-space arrow into the lower bowl or central gap, as part of the B itself, so it means collect/save without a separate oversized download arrow. Prioritize recognizable B first, layered tower second, save cue third. NO BOOKS, no open pages, no leaves, no cloud, no globe, no media-play triangles, no literal detailed architecture. Flat vector-like silhouette, 2-3 solid colors maximum: deep teal background #163F46, ivory B #FAF6EA, restrained mint accent #A5E4CE on one upper tier. Huge bold simple shapes, generous spacing, beautifully balanced, legible at 16px. Square full-bleed entirely OPAQUE solid teal canvas, no transparency, symbol centered occupies 70-75 percent. No gradients, shadows, texture, lighting, mockups, lettering or words apart from the B-shaped mark. Output a single finished icon, not a concept sheet.
```
