## 已实现的代码路径

- 独立 MCP 运行时与十个工具（包含只读 ASR 指南）、受授权目录限制的客户端、扩展配对与任务归属。
- 原文与顺序附件保存、结果与附件清单、文件校验、任务恢复和取消。
- 视频提取音频、兼容封装、媒体时长与完整解码验证；支持明确格式、来源高度、片段范围、字幕语言与图片序号，媒体操作不播放声音。
- 加载前静音的自有任务标签页、静音复用与导航、受限页面操作、目标漂移检查。
- MCP 并发请求与取消传播、明确浏览器实例绑定、`auto/existing/new` 任务标签策略。
- 长结果使用分页文件引用；最多两次自动重试，尊重有界 Retry-After；临时检查点与诊断默认七天到期，只删除登记且未改变的临时文件。
- 媒体工具绝对路径配置与实际版本探测；Codex／Claude 命名 MCP 配置的安装、等待重载状态及指纹核对后撤销。
- 有界作者续帖、引用与转发关系模型及分节文档；关系算法通过受控夹具，真实平台选择器尚未验证。
- 用途优先的 `auto` 选择：有唯一明确主体的 `mixed` 内容会连同可确认的正文／图片保存相应视频、音频或附件；仅当同一目标同时提供独立视频和音频、且没有明确 `include`、`save_as` 或相关偏好时，才返回 `selection_required`。`job_get` 给出可执行选项，`job_resume(save_as)` 用其中一项继续同一任务，不把“未传枚举”当成固定提问步骤。
- `content.md` 以实际已保存 artifact 的 role／MIME 呈现链接；视频提取出的音频会标为音频并保留“源视频”说明。来源 paragraph 的 Markdown 样式文本会作为原文保留，typed heading／quote／list 仍按已提取结构渲染。
- 保留 9 个来源并新增 GitHub、Hugging Face、arXiv、Anthropic、DeepMind 的实验性规则；OpenAI 尚待实际正文结构证据，不注册空壳；见 platform-status.md。
- 技术正文支持保留缩进的代码、合并单元格表格、来源公式信息和引用链接；arXiv 文档用途强制包含论文 PDF，缺文件不会报告完整。
- 续跑重新核对来源指纹：同资源 ID 的来源变化会重新保存；仅签名更新可复用已校验文件。旧资源文件保留，当前清单只引用本次有效内容。
- 按次正文完整性 proof：运行时拒绝无 proof 的 `complete`，并绑定适配器版本、内容类型／ID、规则边界、任务与来源路由；知乎专栏源码规则还要求两次间隔至少 700ms 的只读快照在 URL、正文 block 和按序主资源来源上完全一致。旧 `partial/unknown` 仍可保存为部分结果，媒体完整解码判定保持独立。
