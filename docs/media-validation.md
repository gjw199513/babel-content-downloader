## 验证环境与边界

- 完整视频验证使用隔离安装的 yt-dlp 2026.08.19 与 FFmpeg／ffprobe 8.0.1。
- 下载经过适配器声明的主机、HTTPS 端口、公网地址和重定向检查；使用操作员配置的 Cloudflare DoH 与本机可信 CA 文件。未关闭 TLS、修改系统 DNS 或导出浏览器凭据。
- 每个视频任务的输入下载预算为 128 MiB，YouTube 输入文件合计 86,722,167 字节，Bilibili 为 75,167,359 字节。输入和输出同时保存时，磁盘占用分别为 171,182,552 与 150,401,770 字节；下载预算不等于总磁盘占用上限。
- 媒体接口没有导出逐跳请求轨迹，因此不声称下载“没有发生重定向”。
- 原始审计记录和媒体留在本机 `.audit/`，不进入源代码或安装包。发布包只包含本份去除机器路径的验证摘要。
